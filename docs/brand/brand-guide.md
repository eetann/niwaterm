# niwaterm ブランドガイド

アプリの外側（ドキュメントサイト・README・スクリーンショット・告知画像）で niwaterm を見せるときの決まりごと。
アプリ内のターミナル配色はユーザーが設定で変えるものなので、このガイドの対象外。

## コンセプト

niwa は「庭」。ワークスペース・タイル・タブを自分で区切り、TypeScript の設定で育てていく環境を、手入れの行き届いた庭に重ねている。

トーンは**枯山水**。余白を大きく取り、色数を絞り、線を正確に引く。華やかさより「精密で、長く使える道具」に見えることを優先する。

- 影・グラデーション・大きな角丸は使わない。面の差と罫線で区切る
- 装飾は砂紋（`hairline` 色の 1px 横線を 12px 間隔で並べたもの）だけ。砂紋はターミナルの行にも見える
- **明朝体は使わない**。ターミナルの道具としての硬さと合わないため

## 配色

ライトは枯山水、ダークは苔庭。同じ役割名が両テーマで対応しているので、役割名で指定すれば明暗の切り替えがそのまま成立する。

| 役割 | light | dark | 用途 |
| --- | --- | --- | --- |
| `ground` | `#ece8df` 白砂 | `#141a15` 夜苔 | ページの地 |
| `surface` | `#e3ded2` | `#1e261f` 石畳 | サイドバー・カード |
| `ink` | `#1f1f1c` 墨 | `#e4e2d6` 和紙 | 本文 |
| `ink-muted` | `#5e5c55` | `#a9ae9f` | 補足・キャプション |
| `hairline` | `#d5cfc1` | `#2c372d` | 装飾の細罫・砂紋 |
| `rule` | `#1f1f1c` | `#6f786c` | 操作できる要素の枠線 |
| `stone` | `#8a877e` | `#6f776c` | ロゴの鉢・装飾面（文字には使わない） |
| `sprout` | `#7e9b68` 若苔 | `#93b87a` 苔 | ロゴの芽・ブランドの小さな面 |
| `link` | `#2c4770` 藍 | `#93b87a` 苔 | リンク・フォーカス |
| `lantern` | `#87560f` | `#e2ae62` 灯籠 | 注意・ハイライト（一点だけ） |
| `action` / `action-ink` | `#1f1f1c` / `#ece8df` | `#93b87a` / `#141a15` | 主ボタンの面と文字（1画面に1つ） |
| `code-bg` / `code-ink` | `#1f1f1c` / `#ece8df` | `#0e120f` / `#e4e2d6` | コードブロック |
| `prompt` | `#a9c08f` | `#93b87a` | コードブロック内の `$`・`❯` |

- ライトの `sprout` は文字に使わない。白砂とのコントラストが 2.5:1 しかない
- コードブロックは両テーマとも暗い面にする。ターミナルの画面らしさを保つため

## 書体

| 役割 | 書体 | 備考 |
| --- | --- | --- |
| 見出し・本文 | Zen Kaku Gothic Antique | 見出し 900/700、本文 400。本文の行間は 1.8 |
| コード・ラベル | Spline Sans Mono | 日本語グリフを持たないため、和文は BIZ UDGothic などの等幅へ落ちる |

## ロゴ

`>` のプロンプトと、鉢から出た芽の組み合わせ。角をほぼ立てたタイル（一辺 100 に対して角丸 8）に収める。

- [logo.svg](./logo.svg) — 明るい地（light）用
- [logo-dark.svg](./logo-dark.svg) — 暗い地（dark）用

名前は常に小文字の `niwaterm` と書く（文頭でも `Niwaterm` にしない）。読みは「にわたーむ」。
