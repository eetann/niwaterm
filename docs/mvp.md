# MVP

## コンセプト

- ターミナル・ターミナルマルチプレクサ・ワークスペースを統合したデスクトップアプリ
- 最近のターミナル（Ghostty、Warp、cmux、Orcaなど）と、Obsidian・Vivaldiのような高いカスタマイズ性を両立する
- CLIだけに縛られず、GUIも自然に組み合わせられる開発環境を目指す

## カスタマイズ性

- あらゆる挙動を柔軟にカスタマイズできる
- TypeScriptによる設定
- ヘルパー関数なども利用可能
- キーバインドを自由に変更可能

## 日本語対応

- 日本語入力を快適に利用できる
- 日本語フォント周りの問題をできるだけ解消する

## ワークスペース

- サイドバーを持つ
- ワークスペース・タイル・タブの切り替えでUI全体が大きく変化しない
- サイドバーに任意の情報を表示できる
- AIエージェントなど、長時間動作するものへ素早くアクセスできる

## ターミナル

- ターミナルマルチプレクサとして利用できる
- CLIからターミナル全体を操作できる
- 特定タブへのキー送信などをサポートする
- 画像表示をサポート
- True Color対応
- OSC対応

## GUI

- ブラウザを内蔵する
- HTMLベースのUIを表示できる
- CLI・TUIだけでは難しい操作や可視化をGUIで実現できる
