| --- | --- |
| `nfd-dakuten.csv` | NFD形式の「ディスプレイ」（テ＋結合用濁点U+3099、フ＋結合用半濁点U+309A）。濁点が基底文字と合成されて表示され、Neovimの`$`でカーソルが行末の文字に乗るか。macOSのファイル名はNFDで保存されるため、パスを書いたファイルで出やすい |

中身はバイト列が意味を持つので、エディタで開いて保存し直さないこと（NFCへ正規化されることがある）。
