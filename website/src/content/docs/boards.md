## Boardに自動で付く名前

名前を付けていないBoardには、自動で名前が付く。デフォルトでは、フォーカス中のタブが今いるディレクトリの名前になる。付け方は`board.naming`で変えられる。

```ts
board: {
  naming: "directory",
},
```

| 値                                 | 付く名前                                                           |
| ---------------------------------- | ------------------------------------------------------------------ |
| `"directory-follow"`（デフォルト） | フォーカス中のタブが今いるディレクトリの名前。`cd`するたびに変わる |
| `"directory"`                      | Boardを開いたディレクトリの名前。あとで`cd`しても変わらない        |
| `"sequential"`                     | `Board 1`のような連番                                              |

ディレクトリの名前を使うには、[シェル統合](/niwaterm/shell-integration/)が必要。入れていないシェル（PowerShellなど）では連番になる。

自分で付けた名前は、自動の名前より優先される。名前はprefix + `,`か、サイドバーのBoardをダブルクリックして変える。名前を空にして確定すると、自動の名前に戻る。

## 作業フェーズを付ける

Boardに「実装」「レビュー」のような作業フェーズを付けると、サイドバーのBoard名の下にバッジが出る。ワークツリーごとにBoardを分けているとき、どれが今どの段階かを一覧で見渡せる。

フェーズの候補は`board.phases`に並べる。

```ts
board: {
  phases: [
    { id: "plan", label: "プラン作成", color: "#89b4fa" },
    { id: "implement", label: "実装", color: "#a6e3a1" },
    { id: "review", label: "レビュー", color: "#f5c2e7" },
  ],
},
```

| 項目    | 内容                                                                                           |
| ------- | ---------------------------------------------------------------------------------------------- |
| `id`    | CLIやキーバインドからフェーズを指すときの名前。英数字と`_` `-` `.` `:`で、64文字まで           |
| `label` | バッジに出す名前。省略すると`id`がそのまま出る                                                 |
| `color` | バッジの色。省略すると[`appearance.ui.accent`](/niwaterm/appearance/#枠やバッジの色)の色になる |

フェーズは次のどれかで付ける。

- サイドバーのBoardを右クリックして「フェーズ」から選ぶ
- コマンドパレットから選ぶ
- キーを割り当てる。`set-board-phase`は候補から選ぶ画面を開き、`set-board-phase:<id>`はそのフェーズを直接付ける（[アクション一覧](/niwaterm/keybindings/actions/#board)）
- CLIの`niwa board phase set <id>`を使う（[基本のコマンド](/niwaterm/cli/commands/)）

付けたフェーズは、niwatermを終了しても残る。

## 新しいタブを開く場所

新しいタブやタイルは、デフォルトでは今のタブと同じディレクトリで開く（[シェル統合](/niwaterm/shell-integration/)が必要）。`board.newTabCwd: "worktree"`にすると、そのBoardに紐づけた[ワークツリー](/niwaterm/worktrees/#boardに紐づくワークツリー)のディレクトリで開くようになる。サブディレクトリへ`cd`したあとでも、新しいタブはワークツリーの一番上から始まる。

```ts
board: {
  newTabCwd: "worktree",
},
```

タブの追加・タイルの分割・ポップアップが対象になる。Boardにワークツリーを紐づけていないときは、今のタブと同じディレクトリで開く。

新しく作ったワークスペースの最初のタブは、ホームディレクトリで開く。別のディレクトリにしたいときは`workspace.defaultCwd`に絶対パスを書く。

```ts
workspace: {
  defaultCwd: "/home/me/projects",
},
```

## サイドバーでBoard名の下に出す情報

サイドバーでは、Board名の下に作業フェーズのバッジ・ブランチ名・AIエージェントの状態が出る。何をどの順で出すかは`sidebar.boardStatus`で変える。並べた順に上から出て、書かなかったものは出ない。`[]`にするとBoard名だけになる。

```ts
sidebar: {
  boardStatus: [
    "builtin:agent",
    { source: "builtin:branch", prefix: "" },
    { source: "tab-var:ticket", prefix: "#", color: "#f9e2af" },
  ],
},
```

| 値                 | 出るもの                                                                              |
| ------------------ | ------------------------------------------------------------------------------------- |
| `"builtin:phase"`  | [作業フェーズ](#作業フェーズを付ける)のバッジ                                         |
| `"builtin:branch"` | ブランチ名（`on main`のように出る。[シェル統合](/niwaterm/shell-integration/)が必要） |
| `"builtin:agent"`  | [AIエージェント](/niwaterm/agents/)の状態                                             |
| `"tab-var:<name>"` | [タブ変数](/niwaterm/cli/commands/#タブ変数tab-var)`<name>`の値                       |

デフォルトは`["builtin:phase", "builtin:branch", "builtin:agent"]`。値がないものは詰めて表示するので、空の行はできない。

`{ source, prefix, color }`の形で書くと、値の前に付く文字（`prefix`）と文字の色（`color`）を変えられる。`prefix: ""`にすると、ブランチ名の前の`on`のような、もともと付いている文字を消せる。作業フェーズのバッジの色は、ここではなく`board.phases`の`color`で変える。

`tab-var:<name>`を使うと、自分で決めた値を出せる。たとえばタブで`niwa tab var set ticket 1234`を実行すると、上の例ではBoard名の下に`#1234`と出る。Boardにタブがいくつもあるときは、フォーカス中のタブの値が出る。

## Boardを全部閉じてもワークスペースは残る

ワークスペースの中のBoardをすべて閉じても、ワークスペースは名前も並び順もそのまま残る。画面の中央に出るボタンから、新しいBoardを作れる。レビュー待ちの作業のように、いつも開いているとは限らない作業の置き場所として使える。

ただし、ウィンドウにワークスペースが1つしかないときは、最後のBoardを閉じるとウィンドウも閉じる。
