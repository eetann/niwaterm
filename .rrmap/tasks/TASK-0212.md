## 方針

tmuxの`bind -T copy-mode-vi`と同じく、コピーモード用のキーの表を足す。

- API: `niwa.keybind(key, action, { mode: "copy" })` / `niwa.unbind(key, { mode: "copy" })`。
  検索文字列の入力中（`/` `?` の後）の表は`mode: "copy-search"`
- オブジェクト形式: `keybindings.copyMode` / `keybindings.copyModeSearch`
- アクション名は`copy-`接頭辞（`copy-cursor-left`・`copy-top`・`copy-yank`…）。検索入力中は`copy-search-confirm`等
- キー表記は既存DSLと同じ（英大文字は`shift+g`、記号はそのまま）。コピーモードの表は`ctrl`/`cmd`も付けられる
- 空白区切りで連続キーを書ける（`"g g"`）。既存のpendingGを汎用の「途中まで打った列」に置き換える
- 関数ハンドラも割り当てられる（押したら呼ぶだけで、選択範囲などは渡さない）
- 照合はbun側で行う（コピーモードの状態・関数ハンドラのレジストリがbunにあるため）。
  webviewはキーを正規化した候補列と、検索文字列へ足す1文字を送る
- 検索入力中、表に無い1文字キーは従来どおり検索文字列へ足す
- `niwa keybind list`にコピーモードの表も出す。ドキュメント（jump-and-copy・keybindings・actions・object-format）を更新
