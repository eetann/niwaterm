「掴んだ辺だけ動き反対側は固定」というOSのウィンドウと同じ挙動にしたいので、位置(x/y)の状態も
持たせた。あわせてツールバーのドラッグでの移動も入れている。

## 決めたこと

- 単位は位置・サイズともウィンドウに対するパーセント。`x + width <= 100`を保つだけで
  ウィンドウのリサイズに追従でき、画面外へはみ出さない
- 幾何計算は`src/shared/popup-geometry.ts`に置き、bunとmainviewで同じクランプを通す。
  webviewが送る値とbunが保存する値が一致するので、ドラッグ確定後のエコー待ちの一致判定が外れない
- 値を保持するのは今開いているポップアップだけ。`popup toggle`では維持、`close`/`promote`で破棄。
  localStorageや設定ファイルへは保存しない
- PTYへのresizeはドラッグ中は送らず、pointerupで1回だけ（タイル境界のドラッグと同じ）
- 中央寄せは`inset: 0` + `margin: auto`で行う。`translate(-50%, -50%)`だと端数ピクセルの
  transformでターミナルの文字がにじむ
- ADR 0005の「位置指定は決めていない」行は今回触らない（ユーザー判断）

## 実機で確認したこと（Windows、niwaterm-wip）

四隅・四辺のドラッグで掴んだ辺だけが動き反対側が固定されること、ツールバーのドラッグで
サイズそのまま移動できること、ボタン（昇格・最小化・閉じる）が従来どおり効くこと、
最小サイズ（120x80px）とウィンドウ境界で止まること、離した時にPTYが追従すること
（80%で37x194 → 縮めて19x102）、`popup toggle`で隠して出しても維持されること、
`popup close`→`popup open`で中央80%へ戻ること、OSウィンドウを1695x930から1100x700へ
縮めても右下に寄せたポップアップがはみ出さないこと。
