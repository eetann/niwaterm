`config.md`（1500行超）・`cli.md`・`worktree.md`の中身を、下の表の機能別ページへ移す。同じ機能の設定とCLIの説明は1ページにまとめる（MILESTONE-0017の「決めたこと」）。1ページは200行前後を目安にする。

このタスクでは中身を書き足さず、移して並べ直すことに集中する。`getting-started`・`concepts`の新しい説明はTASK-0194、`shell-integration`・`agents`の導入手順はTASK-0195で書く。`cli`の索引と`cli/commands`はTASK-0192で作る。

## ページ構成

| グループ | トピック名 | 中身（出どころ） |
| --- | --- | --- |
| はじめる | `getting-started` | CLIのセットアップ（cli「セットアップ」）、`niwaterm init`・設定ディレクトリ（config「セットアップ」）、ホットリロード、現在の設定値を確認する |
| | `concepts` | ワークスペース・Board・タイル・タブの関係（TASK-0194で新規に書く） |
| | `shell-integration` | シェル統合、シェル補完（cli） |
| キーボード | `keybindings` | 関数ベースAPI、repeatによる連打、一覧での説明表示、複数ファイルへの分割 |
| | `keybindings/api` | niwa APIの一覧表 |
| | `keybindings/object-format` | オブジェクト形式（従来） |
| | `jump-and-copy` | ジャンプヒント、プロンプトジャンプ、コピーモード |
| 見た目 | `appearance` | 外観設定（配色・タブバー・タイル・背景・タイトルバー） |
| Boardと画面 | `boards` | ワークスペース設定、Board設定（自動命名・作業フェーズ）、サイドバー設定、Boardが0個のワークスペース（cli） |
| | `status-bar` | ステータスバー（config）と`status-bar`コマンド（cli） |
| | `layouts` | レイアウト（config）、`layout list`/`apply`・ビルトインのプリセット・起動時レイアウト（cli） |
| | `layouts/project-local` | プロジェクトローカルのレイアウト（cli）。TASK-0129の`.niwaterm/config.ts`の例もここへ載せる |
| ワークツリー | `worktrees` | worktree.mdの一覧・作成・リモート・開く・削除・置き場所・Boardとの紐づけ・GUIから使う、ワークツリー（config） |
| | `worktrees/hooks` | 作成後フック、レイアウトプリセットの適用、Boardを開いた後のフック、削除前後のフック、プロジェクトローカル設定の承認 |
| マウスとリンク | `mouse-and-links` | マウス設定、選択範囲の右クリックメニュー、リンク設定 |
| | `browser` | ブラウザ設定（config）と`browser`コマンド（cli） |
| 拡張 | `custom-views` | ユーザー定義HTML UI（customViews）、`sidebar switch`（cli） |
| | `hover-buttons` | タブのホバーボタン（hoverButtons）、`tab hover`（cli） |
| | `bell` | ベル（config）と`notify`（cli） |
| シェル | `shell` | シェル設定、シェルプロファイル、ターミナル設定、`shell-profile list`（cli） |
| AIエージェント | `agents` | エージェント統合、Claude Codeのセッション参照（cli） |
| CLI | `cli`・`cli/commands` | TASK-0192 |

ページの並び順はStarlightの`sidebar`設定でグループごとに指定する。トピック名が変わるので、`niwaterm docs show config`・`worktree`を書いている箇所（`.agents/skills/niwaterm-cli/SKILL.md`・README類など）を`grep -rn "docs show" --exclude-dir=node_modules .`で洗い出して直す。

## 決めていないこと

- 「既知の制約」「コマンド命名規則」「AIエージェント向けの導線」「スコープ外」の節は利用者向けではないので、`.agents/`・`docs/`へ移すか消すかを移しながら決める
