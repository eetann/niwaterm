## 方針
- `sidebar.toolbar: { left, right, css } | false`。部品はstatusBarと同じ書き方（id/source/render/interval/prefix/color/tooltip/run）に、icon（lucide名）・label・html・action（キーバインドのアクション名）を足す
- デフォルトは`right: ["builtin:command-palette"]`
- bun側の評価器はステータスバーと共有（src/bun/status-bar.tsのcreateComponentEvaluator）
- macOSでタイトルバーを隠すと信号機ボタンが左端に重なるので、左区画を72pxずらす
