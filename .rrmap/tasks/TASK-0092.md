次のように「コマンドの特定部分だけを書き換えて使い回すコマンド」で便利そう

```sh
foo --from 2026-09-20 --to 2026-09-24 --file project-red-92.csv
```

例: `niwa worktree new`のワークスペース指定。ブランチ名とワークスペースだけを毎回差し替えたい

```sh
niwa worktree new feat/sidebar-dnd --workspace <workspaceId>
```

workspaceIdは`niwa list`で調べて書き写す必要があり、名前に絵文字が入っていると名前での指定も打ちにくい。
テンプレートとして保存しておき、モーダルにフォームみたいに表示され、差し替え部分（ブランチ名・ワークスペース）だけを選択・入力。入力し終わったらsubmitボタンでアクティブなペインに入力される。コピーして閉じるだけの挙動も足したい

ユーザーは設定ファイルにてそのテンプレートを書ける。
コマンドパレット・ホバーボタン・キーバインドなどから呼び出せるようにしたい

## 決まった仕様

モックは案B（フォーム型）を採用: https://claude.ai/artifact/R8sNyPfXBb5neWwMFYkDqx

### 設定ファイル

```ts
commandTemplates: [
  {
    id: "worktree-new",
    name: "worktreeを作る",
    description: "ブランチを切ってworktreeを作り、選んだワークスペースにBoardを開く",
    command: "niwa worktree new {{branch}} --workspace {{workspace}}",
    fields: {
      branch: { label: "ブランチ名", placeholder: "feat/..." },          // 自由入力
      workspace: { label: "ワークスペース", options: "workspace" },      // 組み込みの候補源
      env: { options: ["dev", "stg", "prod"] },                          // 固定の選択肢
      file: { options: async (tab, niwa) => [{ label: "…", value: "…" }] }, // 関数で作る選択肢
    },
    rememberLastValues: false,
  },
],
```

- 差し替え部分は`{{name}}`で書く（`${}`はシェル変数と衝突するため）
- 欄の種類: 自由入力・固定の選択肢・関数で作る選択肢・組み込みの候補源（`"workspace"`など）
- 選択肢は表示名（label）と入れる値（value）を分ける。絵文字入りの名前で選び、idが入る
- `rememberLastValues: true`で前回の値を初期値にする（デフォルトはオフ）
- 値はデフォルトでシェル用にクォートする。fieldごとに`quote: false`で外せる

### モーダル（フォーム型）

- 上にコマンドのプレビュー、下に欄ごとの入力・選択。フォーカス中の欄に対応する箇所をプレビューで強調する
- Tabで欄移動。操作は3つ
  - 貼る（Enter・既定）: アクティブなタブへEnterなしで入力する
  - 貼って実行（Ctrl+Enter）
  - コピーして閉じる（Ctrl+Shift+C）
- 空の欄があれば貼る・貼って実行・コピーを止める
- 貼る先の種類（ターミナル以外のタブ等）は特に区別しない

### 呼び出し

- コマンドパレットの「テンプレート」カテゴリ → 選ぶとモーダル
- キーバインド・ホバーボタンからはniwa API（例: `niwa.commandTemplate.open("worktree-new")`）で直接モーダルを開く
