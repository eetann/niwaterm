## 決めたこと

- 利用者へ配るスキルはリポジトリ直下の`skills/niwaterm/SKILL.md`に置く。`npx skills add eetann/niwaterm`やagent-skills-nix（`subdir = "skills"`）で入れる想定で、`agent setup`からは入れない
- `.agents/skills/`の開発用スキルには`metadata.internal: true`を付け、`npx skills`の候補に出ないようにした（`bunx skills add . --list`で`niwaterm`の1件だけになるのを確認）
- スキルにはよく使うコマンド（`list --json`・`tile split`・`tab new`・`tab send-keys`・`tab capture`・`tab focus`・`notify`）と調べ方だけを書き、残りは`niwa docs search`/`show`へ誘導する
- `niwa docs search <keyword...> [--json]`を追加。大文字小文字無視、複数語は全部を含むページだけ、出現回数順、ページ名・見出し・行番号付きで1ページ5行まで（`--json`は全行）。当たらなければ終了コード1
