コマンドパレットはKEYBIND_ACTIONSと1対1で、漏れていたのは「アクションが存在しない操作」だった。
CLI・マウスからしか届かなかった操作をアクション化して、パレット・キーバインド・サイドバーから使えるようにした。

追加したアクション: new-board / close-board / clear-board-startup / rename-workspace /
close-workspace / close-window / promote-popup（いずれも既定キーなし）。
あわせてコマンドパレットへ「Switch to Board: <名前>」「Switch to Workspace: <名前>」を動的項目として並べ、
サイドバーのワークスペース見出しの右クリックに「新しいBoard」「新しいワークスペース」「削除」を足した。
