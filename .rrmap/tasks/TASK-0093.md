`git worktree list --porcelain`のパースと、リポジトリルート・メインワークツリーの解決を担う層を作る。
以降の new / open / remove / UI が全てここを経由する。

- 取れるようにする情報: ワークツリーのパス、ブランチ名、HEAD、detached、locked、prunable、メインかどうか
- ワークツリーの置き場所（`../<repo>-<branch>`なのか`.worktrees/`配下なのか）の既定と設定での上書き
- `niwaterm worktree list`はniwatermの外からも使えるようにする（Board未使用でも単体で成立させる）
- gitが無い・リポジトリ外・worktree未対応バージョンといった異常系の扱いを決める
