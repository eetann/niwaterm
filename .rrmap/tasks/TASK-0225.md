v1.4.0で`GHOSTTY_TERMINAL_OPT_PROGRAM_STATUS`（OSC 7501）が増えた。プログラムがidle/working/done/blocked/errorの状態、blockedの理由（permission/question/auth）、進捗%、`app`（例: `"claude-code"`）、title/messageを報告するプロトコル。
サイドバーのエージェント状態は今`niwa tab var set agent_status`を呼ぶhook頼みだが、対応したプログラムならhook無しで取れる。
まずどのツールがOSC 7501を送るか調べる。
