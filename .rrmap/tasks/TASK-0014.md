## 意思決定

DECSCUSR（カーソル形状）は`ghostty_terminal_get`のGhosttyTerminalDataには存在せず、
render state API（`ghostty_render_state_new/update/get` +
`GHOSTTY_RENDER_STATE_DATA_CURSOR_VISUAL_STYLE`）経由でのみ読める。
niwaterm側はrow iterator等render stateの他機能は使わず、terminal 1つにつき
render state 1個（`src/bun/ghostty.ts`の`cursor()`内で毎回updateして形状だけ読む）
という最小構成で導入した。

blink（DECSCUSRの点滅指定）は今回は対象外。`GHOSTTY_RENDER_STATE_DATA_CURSOR_BLINKING`
で同様に取得できるはずなので、対応する場合はここを起点にする。
